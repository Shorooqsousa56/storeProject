# MyStore

This is a simple e-commerce web application built with Angular for the frontend and Node.js/Express + SQL database for the backend.

# Projrect Setup

# Backend

1- Navigate to the backend folder
cd storeBack
cd storefrontProj

2-Install dependencies
npm install

3-Run database migrations to create tables and initial data

npm run migrate

4-Start the backend server
npm start

# Frontend

1-Navigate to the frontend folder
cd storefront
cd my-store

2-Install dependencies
npm install

3-Serve the Angular app
ng serve

# Usage

Open your browser and go to http://localhost:4200/products to see the product list.

Click on a product to view details.

Add products to the cart and adjust quantities.

Checkout to see the confirmation page with your name and total price.
